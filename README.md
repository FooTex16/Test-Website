# 🌟 EduVerse — Semesta Belajar Interaktif SD

> **Platform Edukasi Gamifikasi Terpadu untuk Siswa Sekolah Dasar Kelas 1–6 (Fase A, B, C) berbasis Kurikulum Merdeka**

---

## 🚀 Fitur Unggulan

- **🧭 7 Dunia Kurikulum Terpadu**:
  - 🧮 **Pulau Numeria**: Pecahan pizza interaktif, logika berhitung, dan geometri 3D.
  - 🔬 **Galaksi Sains & Biosfer**: Tata surya, daur air hujan, dan laboratorium aman.
  - 📚 **Lembah Kata**: Dongeng nusantara, literasi, dan ekspedisi kosa kata.
  - 💻 **Zona Cyber Cerdas**: Keamanan digital anak, etika siber, dan sandi aman.
  - 🏛️ **Pulau Budaya & Pancasila**: Bhinneka Tunggal Ika, gotong royong, dan rumah adat.
  - 🎨 **Atelier Seni & Kriya**: Harmoni warna, lagu daerah, dan eksplorasi kriya.
  - 🏃‍♂️ **Taman Raga & Sehat**: Nutrisi isi piringku, postur tubuh, dan kebugaran.

- **🤖 Olu AI Companion**:
  - Robot pemandu ramah anak dengan gaya bimbingan Socratic.
  - Penjelasan analogis visual konkret yang sabar dan membangkitkan rasa ingin tahu.
  - Dilengkapi Text-to-Speech (TTS) suara ramah anak dan efek suara synthesizer lembut.

- **🏙️ EduVerse City**:
  - Bangun kota impian menggunakan kepingan *Star Shards* yang dikumpulkan dari misi harian.
  - Gedung edukatif: Menara Logika, Taman Sains, Pohon Dongeng, Observatorium Galaksi, dan Museum Budaya.

- **🎮 Mini Games Edukatif**:
  - *Astro Dash*: Misi hitung cepat angkasa.
  - *Science Lab*: Eksperimen virtual fotosintesis dan daur air.
  - *Ekspedisi Kata*: Teka-teki susun balok huruf nusantara.
  - *Benteng Sandi*: Klasifikasi privasi data aman vs rahasia.

- **🛡️ Aman & Ramah Anak**:
  - 100% Bebas Iklan & Tanpa Pelacak Eksternal.
  - Pengingat Waktu Layar (Screen Time Alert) setiap 20 menit belajar.
  - Gerbang Dewasa (Adult Gate PIN) untuk Guru & Orang Tua.
  - Dashboard Analisis Progres Siswa untuk Guru dan Pantauan Orang Tua.

## 🛠️ Panduan Menjalankan Secara Lokal

**Prasyarat:** Node.js (v18+ direkomendasikan)

1. **Clone repository:**
   ```bash
   git clone https://github.com/FooTex16/Test-Website.git
   cd Test-Website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Jalankan aplikasi (Mode Development):**
   ```bash
   npm run dev
   ```
   Buka `http://localhost:3000` di browser Anda.

4. **Build untuk Produksi:**
   ```bash
   npm run build
   ```
